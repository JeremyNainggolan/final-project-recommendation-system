#### Overview

- This project introduces the challenge of working with implicit feedback and focuses on a ranking task. 
- The goal is to discover which items (books) a user will interact with.

#### Dataset
- The datasets provided contains interactions of users with books. 
- The dataset contains implicit user preferences. An interaction is recorded only if a user expressed a strong positive preference (i.e., attributed a rating of at least 4). 

#### Metric
- Performance is measured by Mean Average Precision at 10 (MAP@10). This metric evaluates both the relevance and the rank order of the top 10 recommended items.
